# [Тестирование] Задание 1. Проектная группа ÉLAIRE

## 1. Основной пользовательский сценарий (Happy Path): «Клиент записывается на услугу»

```text
Клиент записывается на услугу
│
├── 1. Выбор услуги (Экран 1)
│   ├── 1.1. Открыть сайт салона ÉLAIRE / форму онлайн-записи
│   ├── 1.2. Просмотреть перечень категорий услуг
│   ├── 1.3. Выбрать желаемую категорию (например, «Стрижки и укладки»)
│   ├── 1.4. Просмотреть список услуг выбранной категории с длительностью и ценами
│   ├── 1.5. Выбрать конкретную услугу (например, «Женская стрижка»)
│   └── 1.6. Нажать кнопку «Продолжить» для перехода к выбору даты и времени
│
├── 2. Выбор даты, времени и специалиста (Экран 2)
│   ├── 2.1. Ознакомиться с информацией о выбранной услуге в информационном баннере
│   ├── 2.2. Выбрать мастера (или оставить вариант «Любой специалист»)
│   ├── 2.3. В интерактивном календаре выбрать желаемую дату посещения
│   ├── 2.4. Просмотреть сетку доступных временных слотов на выбранный день
│   ├── 2.5. Выбрать подходящий свободный слот времени (например, «10:00»)
│   ├── 2.6. Проверить рассчитанный интервал времени процедуры в панели действий
│   └── 2.7. Нажать кнопку «Далее» для перехода к вводу контактных данных
│
└── 3. Ввод контактных данных и подтверждение записи (Экран 3)
    ├── 3.1. Ознакомиться с итоговой сводкой записи (услуга, мастер, дата, время, цена)
    ├── 3.2. Ввести имя клиента в поле «Имя»
    ├── 3.3. Ввести контактный номер телефона в поле «Телефон»
    ├── 3.4. (Опционально) Ввести пожелания в поле «Комментарий к записи»
    ├── 3.5. Нажать кнопку «Подтвердить запись»
    └── 3.6. Получить подтверждение успешной записи (экран успеха с деталями бронирования)
```

## 2. Список функциональных требований по сценарию «Запись на услугу» (3 экрана)

### Экран 1. Выбор категории и услуги
1. **Система должна отображать список всех доступных категорий услуг с количеством услуг в каждой категории.**
2. **Система должна отображать список услуг с названием, описанием, продолжительностью и стоимостью, когда клиент выбирает категорию.**
3. **Система должна визуально выделять выбранную услугу и делать активной кнопку «Продолжить», когда клиент выбирает одну из услуг в списке.**
4. **Система должна сохранять выбранную услугу и перенаправлять на экран выбора даты и времени, когда клиент нажимает кнопку «Продолжить».**

### Экран 2. Выбор даты, времени и специалиста
5. **Система должна отображать интерактивный календарь с возможностью переключения месяцев, блокируя для выбора прошедшие даты.**
6. **Система должна загружать и отображать только актуальные свободные временные слоты, когда клиент выбирает дату в календаре.**
7. **Система должна автоматически рассчитывать и отображать время окончания процедуры в панели действий, когда клиент выбирает свободный слот времени.**
8. **Система должна активировать кнопку перехода к следующему шагу («Далее»), когда выбраны дата и доступный временной слот.**

### Экран 3. Ввод контактных данных и подтверждение записи
9. **Система должна отображать сводную карточку записи с информацией об услуге, мастере, дате, времени и стоимости при переходе на экран подтверждения.**
10. **Система должна проверять обязательность и корректность заполнения полей «Имя» и «Телефон», когда клиент нажимает кнопку «Подтвердить запись».**
11. **Система должна отправлять данные бронирования на сервер и отображать экран успешной записи с деталями визита, когда все обязательные поля заполнены корректно и нажата кнопка подтверждения.**
12. **Система должна блокировать повторное нажатие кнопки отправки и отображать индикатор загрузки, пока запрос на создание записи обрабатывается сервером.**
