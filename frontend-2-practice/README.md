# Задание 2. JavaScript — Оживление страницы «Выбор даты и времени»

Интерактивная логика выбора даты и времени для салона красоты **Blossom Beauty** на нативном JavaScript (Vanilla JS).

## Что реализовано:
1. **Предзаполненный день по умолчанию:** При открытии выбран 16 октября 2026 года и слот 11:00.
2. **Листание месяцев:** Кнопки «‹» и «›» переключают месяцы вперед и назад с обновлением сетки дней.
3. **Защита от выбора прошлых дат:** Дни ранее текущей даты (8 октября 2026) отключены, выглядят приглушенно и не кликаются (`disabled`).
4. **Интерактивный выбор дня:** При клике на день он становится активным, генерируются актуальные слоты, а ранее выбранное время корректно сбрасывается.
5. **Интерактивный выбор слота:** Доступные слоты активируются по клику. Занятые слоты отмечены серым цветом и недоступны для выбора.
6. **Динамическая нижняя панель:** Отображает дату, день недели, месяц, год и выбранный диапазон времени (например, `16 октября 2026 · 11:00–12:00`). Кнопка «Далее» активируется только при выбранном времени.
7. **Архитектура скрипта:** Разделение на состояние (State), чистые функции (`buildCalendarGrid`, `compareDates`, `isDateSelectable`), рендер (`renderCalendar`, `renderTimeSlots`, `updateBottomBar`) и делегирование событий.
