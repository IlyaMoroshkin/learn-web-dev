# Задание 1. HTML/CSS — Выбор даты и времени

Вёрстка страницы онлайн-записи салона красоты **Blossom Beauty** по десктопному макету Figma (Экран «04 — Выбор даты и времени»).

## Структура проекта
- `index.html` — семантическая разметка страницы (header, nav, main, section, article, footer).
- `styles.css` — стили проекта (CSS-переменные, типографика Cormorant Garamond и Inter, Flexbox, Grid, состояния hover и active).
- `images/` — директория для графических ассетов.

## Как открыть проект
1. Откройте файл `index.html` в любом современном браузере (двойным кликом или через расширение Live Server в VSCode).
2. Страница сверстана в точном соответствии с утвержденным десктопным макетом Figma (1440px).
