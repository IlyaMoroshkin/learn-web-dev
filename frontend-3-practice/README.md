# Задание 3. Основы React — Выбор даты и времени

Перевод страницы выбора даты и времени для салона красоты **Blossom Beauty** на стек **React + Vite**.

## Структура проекта
```
frontend-3-practice/
├── index.html            # HTML-обертка Vite
├── package.json          # Зависимости React 18 и Vite 5
├── vite.config.js        # Конфигурация Vite
├── src/
│   ├── main.jsx          # Точка входа React (createRoot)
│   ├── App.jsx           # Главный компонент со стейтом (useState, useMemo)
│   ├── index.css         # Стилизация компонентов
│   ├── components/       # Модульные компоненты
│   │   ├── Header.jsx          # Шапка сайта
│   │   ├── Stepper.jsx         # Пошаговый индикатор (этапы 1-5)
│   │   ├── SelectionBanner.jsx # Плашка выбранного мастера
│   │   ├── CalendarCard.jsx    # Календарь с днями недели и навигацией
│   │   ├── TimeSlots.jsx       # Сетка доступных/занятых слотов времени
│   │   ├── ActionsBar.jsx      # Нижняя панель действий и кнопка «Далее»
│   │   └── Footer.jsx          # Подвал сайта
│   └── data/
│       └── date.js       # Чистые функции работы с датами и расписанием
```

## Как запустить проект:
1. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```
2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
3. Откройте адрес, указанный в терминале (обычно `http://localhost:5173/`).
