# ÉLAIRE · Задание 4. Приёмка онлайн-записи

## Карта функционала

```text
Онлайн-запись
├── Каталог
│   ├── Категории → загрузить список → показать счётчики → переключить категорию
│   ├── Карточки → показать название, описание, длительность и цену → выбрать услугу
│   └── Навигация → проверить выбор → сохранить услугу → перейти к расписанию
├── Расписание
│   ├── Специалист → выбрать мастера или «Любой специалист» → обновить слоты
│   ├── Календарь → переключить месяц → заблокировать прошлые даты → выбрать дату
│   ├── Слоты → загрузить свободное время → показать пустое состояние → выбрать слот
│   └── Навигация → вычислить время окончания → проверить дату и слот → перейти к форме
└── Подтверждение
    ├── Сводка → показать услугу, мастера, дату, время и цену
    ├── Контакты → ввести имя → ввести телефон → при желании добавить комментарий
    ├── Валидация → проверить обязательность, алфавит, длину и формат → показать ошибки
    └── Отправка → заблокировать повторное нажатие → создать запись → показать успех
        ├── Конфликт → показать сообщение → обновить слоты → предложить другой слот
        └── Сбой → сообщить об ошибке → сохранить форму → разрешить повторную попытку
```

## Вход в тестирование

1. Стенд открывается, каталог загружается.
2. В каталоге доступны тестовая категория, услуга и карточка с ценой и длительностью.
3. После выбора услуги открывается расписание.
4. Можно выбрать мастера, будущую дату и свободный слот.
5. Экран подтверждения показывает правильную сводку и блокирует отправку без телефона.
6. На стенде успешная запись создаётся один раз и отображается подтверждение. Уведомления отключены или направлены в тестовый приёмник.

Полный прогон начинается после прохождения всех шести пунктов. При блокировке фиксируются пункт, причина и данные окружения.

## Критерии завершения

- Каждое требование связано хотя бы с одной проверкой. Все 19 требований пройдены по матрице, результаты сохранены.
- Все запланированные тесты выполнены, критический путь записи проходит, открытых P1 и P2 нет. Исправления по ним перепроверены.
- Остальные отклонения перечислены с влиянием на пользователя и решением об их принятии или исправлении.
