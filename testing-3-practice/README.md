# ÉLAIRE · Задание 3

## 3.1. Классы эквивалентности и границы

Телефон проверяется в итоговом формате поля после применения маски. Мобильный номер РФ трактуется как `+7 (9XX) XXX-XX-XX`. Проверка принадлежности номера конкретному абоненту в условии не предусмотрена.

| Поле | Класс | Пример | Ожидание |
|---|---|---|---|
| Телефон | 11 цифр, российский мобильный префикс и нужная маска | `+7 (999) 123-45-67` | Принять |
| Телефон | Пустое значение | пусто | Ошибка обязательности |
| Телефон | Меньше 11 цифр | `+7 (999) 123-45-6` | Отклонить |
| Телефон | Больше 11 цифр | `+7 (999) 123-45-678` | Отклонить итоговое значение |
| Телефон | Другой код страны или отсутствует `+7` | `+1 (999) 123-45-67`, `8 (999) 123-45-67` | Отклонить |
| Телефон | Российский немобильный номер | `+7 (495) 123-45-67` | Отклонить |
| Телефон | Нарушена маска или есть посторонние символы | `+79991234567`, `+7 (999) 123-45-6А` | Отклонить ненормализованное значение |
| Имя | 2–40 букв кириллицы, включая Ё/ё | `Алёна` | Принять |
| Имя | Пустое значение | пусто | Ошибка обязательности |
| Имя | 1 буква | `Я` | Отклонить |
| Имя | 41 и более букв | `А` × 41 | Отклонить |
| Имя | Содержит символы вне кириллического алфавита | `Ивaн` (латинская a), `Анна2`, `Анна-Мария`, `Анна Мария` | Отклонить |

| ID | Поле | Значение | Ожидание |
|---|---|---|---|
| TC-09 | Телефон, 10 цифр | `+7 (999) 123-45-6` | Запись не отправляется |
| TC-10 | Телефон, 11 цифр | `+7 (999) 123-45-67` | Поле валидно |
| TC-11 | Телефон, 12 цифр | `+7 (999) 123-45-678` | Итоговое значение из 12 цифр не принимается. Маска может блокировать лишнюю цифру |
| TC-12 | Имя, 0/1/2 символа | пусто / `Я` / `Ёя` | Ошибка обязательности / ошибка длины / принято |
| TC-13 | Имя, 39/40/41 символ | `А` × 39 / 40 / 41 | Принято / принято / значение из 41 символа не принимается |
| TC-14 | Имя, одна замена в валидной строке | `Анна` → `Аннa`, `Анн1`, `Анн-`, `Ан а` | Исходное значение валидно, каждое изменённое отклоняется |
| TC-15 | Телефон, одна замена в валидной строке | `+1 (999) 123-45-67`, `+7 (899) 123-45-67`, `+7 (999) 123-45-6А`, `+7 [999) 123-45-67` | Каждое изменённое итоговое значение отклоняется |

Числовые границы применимы к длине. Для алфавита, префикса и маски переход между классами проверяется изменением одного символа. При изолированной проверке второе поле заполнено валидным значением.

## 3.2. Таблица решений

«Имя заполнено» проверяет наличие значения. Для строк с заполненным именем используется валидное имя `Алёна`. Проверки формата имени вынесены в 3.1. «Телефон валиден» означает корректность формата и мобильного префикса.

| TC-16 / Правило | Имя заполнено | Телефон заполнен | Телефон валиден | Ожидаемое действие |
|---|---|---|---|---|
| R1 | Да | Да | Да | Подтвердить запись, если слот свободен и сервер принял запрос |
| R2 | Да | Да | Нет | Ошибка формата телефона |
| R3 | Да | Нет | Да | Невозможная комбинация |
| R4 | Да | Нет | Нет | Ошибка обязательности телефона |
| R5 | Нет | Да | Да | Ошибка обязательности имени |
| R6 | Нет | Да | Нет | Ошибка обязательности имени и ошибка формата телефона |
| R7 | Нет | Нет | Да | Невозможная комбинация |
| R8 | Нет | Нет | Нет | Ошибки обязательности обоих полей |

При ошибке пользователь остаётся на шаге подтверждения, введённые значения сохраняются, запрос на создание записи не отправляется.
